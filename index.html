口径说明
1. 数据来源：FBI 报表 1818098「FY26财年答疑小蜜汇总」-> 小蜜答疑明细，日期范围 2026-08-01 至 2026-08-26，租户仅包含「商家系统运维小蜜」和「菜鸟/全球供应链/进口供应链」。
2. 业务分类：菜鸟/全球供应链/进口供应链默认「进口供应链」；商家系统运维小蜜从「用户提问表单」JSON 中的业务分类字段提取，无法提取时沿用原字段；仅展示上述六个固定分类，其余归入「其他」；同一分类内按工单量降序排列。
3. 首轮10分钟响应率 = 责任人首答响应时间 < 600 秒（10分钟）的工单 / 有首答响应时间的工单。
4. 1小时解决率 = 责任人会话耗时 / 60 < 60 分钟（即 3600 秒内）的工单 / 有会话耗时的工单（FBI 明细未提供独立「解决时长」，以「责任人会话耗时」替代）。
5. 差评工单数 = 是否差评 =「是」 或 会话状态 ≠「已解决」的工单数（FBI 明细未提供服务分、是否投诉升级字段，以此口径近似）。
6. 答疑交互次数分布：≤3次、4-5次、6-10次、>10次。
7. 达标标准：首轮10分钟响应率 ≥ 80% 且 1小时解决率 ≥ 80% 且 差评工单数 = 0；评价列会列出未达标项。
8. 工单量前三的责任人名称后显示金/银/铜奖牌；页面顶部日期范围可实时筛选表格与指标。
